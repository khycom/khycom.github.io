# Files

다운로드용 문서를 두는 폴더입니다.

| 파일                  | 용도                                          |
| --------------------- | --------------------------------------------- |
| `CV_Hoyoung_Kim.pdf`  | 헤더의 CV 다운로드 버튼이 가리키는 파일        |

영문 페이지(`index.html`)와 국문 페이지(`index_kr.html`)가 이 PDF **하나를
공유**합니다. 국문 CV를 따로 만들려면 파일을 추가한 뒤 `index_kr.html` 의
`class="cv-download"` 링크 경로만 바꾸면 됩니다.

파일명을 바꾸는 경우 두 HTML의 링크를 모두 수정해야 합니다. 경로가 맞지
않으면 버튼은 그대로 보이지만 클릭 시 404 가 납니다.
