# Images

| 파일          | 용도                     |
| ------------- | ------------------------ |
| `profile.jpg` | 사이드바 프로필 사진     |

- 권장 사양: 정사각형 비율(1:1), 400×400px 이상
- 두 언어 페이지가 같은 파일을 공유합니다.
- `style.css` 의 `.profile-photo` 가 `background-image` 로 불러오며,
  180×180px 원형으로 잘라 표시합니다.

> **참고** — 파일이 없으면 이니셜 대신 빈 회색 원이 표시됩니다.
> 폴백 텍스트를 넣으려면 두 HTML의 `.profile-photo` div 안에 직접
> 이니셜("HK")을 써넣어야 합니다.
